# ♻️ Textile Waste Intelligence Platform

A full-stack application for tracking, analyzing, and managing textile waste inventory in real time.

## 🧰 Tech Stack
- **Backend:** FastAPI (Python), Uvicorn, REST API
- **Frontend:** Streamlit
- **Data Handling:** Pandas, CSV Export/Import

## 🚀 How to Run Locally

### 1. Start Backend API
Open Terminal 1:
```bash
cd backend/app
..\..\.venv\Scripts\activate
uvicorn main:app --reload
